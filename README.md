# Java Console Calculator

## Description

A simple Java console calculator that performs basic arithmetic operations using Java.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Handles division by zero

## Technologies Used

* Java
* Visual Studio Code (VS Code)

## How to Run

Compile the program:

javac Calculator.java

Run the program:

java Calculator
